API do Analytics

Bem Vindo a API do Analytics do VTurb

Obrigado pelo seu interesse na API VTurb Analytics. Esta documentação irá ajudá-lo a integrar-se ao nosso poderoso banco de dados de análises e aproveitar os insights de dados para suas aplicações.

Geral

A API do Analytics do VTurb fornece acesso programático ao nosso banco de dados analíticos, permitindo que você:

  • Faça consultas em tempo real e busque dados históricos
  • Gere seus próprios relatórios e gráficos
  • Integre a nossa API diretamente nas suas aplicações
  • Automatize pipelines e auxilie na tomada de decisão do seu negócio
Dica de Integração: Todas as requisições autenticam via cabeçalho HTTP X-Api-Token acompanhado de X-Api-Version: v1. Nenhum dado de sessão de cookie é necessário.

Como Começar

Para começar a utilizar a API do Analytics do VTurb:

  1. Crie uma conta caso você já não possua uma no painel CloudVTurb
  2. Gere uma API key através da sua área de configurações (Configurações > API de Analytics)
  3. Leia o nosso Guia de referência e detalhamento de todos os endpoints disponíveis na nossa documentação
  4. Confira abaixo exemplos de implementação em cURL, JavaScript e Python

Limites de Requisições (Quotas)

A API do Analytics do VTurb implementa limite de requisições para um uso consciente e justo a partir do seu plano:

Plano Janela de 60 segundos Janela de 24 horas Status
Basic Tier 60 requisições / min 2.000 requisições / dia Padrão
Pro Tier 120 requisições / min 10.000 requisições / dia Habilitado
Scale Tier 300 requisições / min 50.000 requisições / dia Alta Escala
Enterprise Tier 800+ requisições / min Ilimitado / Customizado Sob Demanda

Suporte

Se você tiver alguma dúvida ou precisar de ajuda:

  • Veja exemplos de código e casos de uso na seção Analytics.
  • Consulte o monitoramento de cotas em tempo real via endpoint GET /quota/usage.
  • Contate o nosso suporte técnico para dúvidas avançadas de integração.

Autenticação

Autenticação da API

Nossa API utiliza dois cabeçalhos HTTP para se autenticar, sendo eles um para validar a autenticação e outro para escolher a versão da api a ser utilizada. Os dois cabeçalhos precisam estar incluídos em todas as requisições para garantir o sucesso da mesma.

Cabeçalhos Obrigatórios

Cabeçalho Descrição Obrigatoriedade Valor Exemplo
X-Api-Token O seu Token único de autenticação gerado no painel Sim vturb_live_89fa21...
X-Api-Version A versão da API a qual você deseja se conectar Sim v1

Obtendo o seu token de API

  1. Acesse o seu painel do CloudVTurb
  2. Navegue até a seção de configuração de API keys em /settings/analytics-api
  3. Clique em Criar Nova Chave e copie o token gerado
  4. Armazene-o de forma segura em variáveis de ambiente do seu servidor

Exemplo de Requisição

curl -X POST "https://dash.roleta-sorte.online/conversions/active_platforms" \
  -H "X-Api-Token: vturb_live_seu_token_aqui" \
  -H "X-Api-Version: v1" \
  -H "Content-Type: application/json" \
  -d '{}'

Respostas de Erro de Autenticação (401)

Se os cabeçalhos X-Api-Token ou X-Api-Version estiverem ausentes ou inválidos, a API retornará HTTP 401 Unauthorized:

Response: 401 Unauthorized 
{
  "error": "Unauthorized",
  "message": "Missing proper X-Api-Token or X-Api-Version"
}

Changelog

Release Notes

Histórico de versões, melhorias e correções da API VTurb Analytics.

Versão 1.0.3 (2025-05-15)

Melhorias

Melhorada a performance dos seguintes endpoints:

  • /events/total_by_company_day

Detalhamento

Algumas vezes durante a requisição de alguns usuários, os mesmos estavam atingindo o limite de recurso permitido, porém o request em questão não requisitava muitos dias de dados. Isso foi normalizado através de uma otimização no agregador de eventos temporais, reduzindo o consumo de memória e CPU em até 75%.

Versão 1.0.2 (2025-05-15)

Melhorias

Melhorias para lidar com exceções em requests que utilizam mais recursos do que o permitido considerando o plano da empresa:

  • Adicionado controles específicos para lidar com o erro AUTHENTICATION_FAILED
  • Adicionado controles específicos para lidar com o erro MEMORY_LIMIT_EXCEEDED

Versão 1.0.1 (2025-05-15)

Correções de Bugs

Corrigido o tratamento de fuso horário no endpoint /sessions/stats_by_field_by_day para garantir relatórios de data consistentes em diferentes fusos horários (como America/Sao_Paulo GMT-3). Isso afeta:

  • Estatísticas de sessão por dia
  • Taxas de conversão
  • Timestamps de eventos
  • Agregações baseadas em data

Versão 1.0.0

Lançamento Oficial da API

Disponibilização pública da API VTurb Analytics com 28 endpoints completos, suporte a cabeçalhos X-Api-Token e X-Api-Version: v1, cotas dinâmicas e integração nativa com rastreamento UTM, retenção segundo a segundo e testes A/B.

Preencha os dados cadastrais obrigatórios para liberar o acesso total:

Confirmação

Novo webhook
? Para onde os eventos são enviados. Precisa ser um endereço HTTPS que responda com status 2xx.
Campo obrigatório
? Usado para validar a integridade no header webhook-signature da sua requisição.
O que seu endpoint recebe

Cada entrega é um POST com estes headers e um corpo JSON.

Headers 
content-type: application/json
user-agent: VTurb-Webhooks/1.0
webhook-id: evt_01m0ddbgsya6f5ne8nk6fmvm5a
webhook-signature: whsec_exemplo_assinatura_secreta_aqui
Corpo 
{
  "event_id": "evt_01m0ddbgsya6f5ne8nk6fmvm5a",
  "event_type": "video.upload.completed",
  "v": 1,
  "org_id": "6a85d79fa5267d77ef2717ae",
  "occurred_at": "2026-08-19T16:23:31.000Z",
  "data": {
    "video_id": "6a85d880a5267d77ef271818",
    "name": "my-video.mp4",
    "size_bytes": 3635130,
    "source": "dashboard"
  }
}

Seu endpoint precisa responder 2xx. Entregas com falha são reenviadas automaticamente e o mesmo evento pode chegar mais de uma vez, então faça a deduplicação por event_id.
